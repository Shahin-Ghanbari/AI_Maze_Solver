# Interactive Maze Solvers

Two Python desktop demos for solving a maze you design. The A* demo uses Manhattan distance to guide its search. The other demo uses rule-based backward chaining.

## Run locally

You need Python 3 with Tkinter. Run `python -m tkinter` to check that it opens a window.

```bash
python "A*.py"
python "Rull-Based Backward Chaining.py"
```

Run either command to open its demo. Create a grid, mark walls, then select the start and goal and click **Find Path**.
